# 📚 Reading Notes

> 一个持续记录阅读过程的个人阅读档案系统。

每一本书对应一个独立 HTML 文件，从开始阅读到最终完成，持续记录整个阅读旅程。

## ✨ 核心理念

不是只记录“这本书讲了什么”，而是记录：

- 我为什么开始读这本书
- 我从什么时候开始阅读
- 我读了多少次
- 每次读了哪些内容
- 我花了多少时间
- 我记录了哪些金句
- 我当时有什么思考
- 最终这本书给我留下了什么

## 📁 项目结构

```
reading-notes/
├── README.md
├── books/
│   └── 每本书一个 HTML 文件
├── templates/
│   └── book-template.html
└── skill/
    └── SKILL.md
```

## 🚀 使用方式

### 1. 新建一本书

提供：

```
书名：
作者：
全书总页数：
为什么开始读这本书：
开始阅读日期：
书籍封面：
```

系统会创建：

```
books/书名.html
```

并初始化阅读状态、阅读进度、阅读次数和阅读时间。

### 2. 新增一次阅读记录

提供：

```
书名：
开始页码：
结束页码：
已读章节：
本次阅读时间：
本次阅读内容概述：
金句摘抄及对应感悟：
本次阅读感悟：
```

系统自动更新：

- 阅读次数
- 已读页数
- 阅读进度条
- 总阅读时间
- 阅读记录目录
- 阅读时间轴

### 3. 完成一本书

当达到全书总页数或明确表示读完后，系统自动更新：

- 阅读状态：🎉 已读完
- 阅读进度：100%
- 完成日期

然后记录最终的：
